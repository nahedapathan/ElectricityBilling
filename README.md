# ElectricityBilling
# ⚡ Electricity Billing System

A full-stack enterprise-level Electricity Billing System developed for the Maharashtra Electricity Board using Spring Boot and Angular.

This project helps manage electricity customers, meters, taxes, and bill generation through a modern web-based system with clean architecture and scalable design.

---

# 🚀 Project Overview

The Electricity Billing System is designed to automate electricity bill management and reduce manual work for electricity board operations.

The application provides:

- Customer management
- Meter management
- Tax management
- Bill generation and tracking
- REST API integration
- Responsive Angular frontend
- Clean and scalable backend architecture

---

# ✨ Features

## 👤 Customer Management
- Add new customers
- Update customer details
- Delete customers
- View customer information

## ⚡ Meter Management
- Assign meters to customers
- Meter type management
- Phase code management
- Installation tracking

## 💰 Tax Management
- Create electricity tax configurations
- Update tax percentages
- Manage multiple tax types

## 🧾 Bill Management
- Generate electricity bills
- Track bill status
- Calculate bill amount
- Manage billing history
